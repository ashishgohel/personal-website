# Personal Portfolio Website

## Overview
This is a personal portfolio website for Ashish Gohel, showcasing skills, projects, and professional background.

## Tech Stack
- HTML5
- Tailwind CSS
- JavaScript
- Vite

## Setup
1. Clone the repository
2. Run `npm install`
3. Run `npm run dev` to start the development server
4. Run `npm run build` to create a production build

## Deployment
Hosted on GitHub Pages
